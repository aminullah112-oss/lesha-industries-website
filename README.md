# Lesha Industries — Website

Marketing website for **Lesha Industries**, an industrial equipment supplier and service provider based in Jeddah, Saudi Arabia.

**Live preview:** https://aminullah112-oss.github.io/lesha-industries-website/

## Pages

- `index.html` — Home
- `products.html` — Product catalog (8 categories)
- `services.html` — Services (11 capabilities)
- `about.html` — About the company
- `contact.html` — Contact form, details, and map

## Running locally

```bash
node server.js
```

Then open `http://localhost:5500`.

## Structure

- `css/style.css`, `js/main.js` — shared styles and behavior
- `assets/gallery/` — real product & service photography, organized by category
- `assets/clients/` — partner/client logos
